# firdi-yy

食研所 (FIRDI) 相關管理系統與工具集。

## 網頁工具

您可以在開啟 GitHub Pages 後透過以下連結使用工具：

1.  **[留樣管理系統](https://yi622.github.io/firdi-yy-/)** (`index.html`)
    *   用於管理食品留樣紀錄。
    *   提供過期提醒功能。

2.  **[產品配方感官品評系統](https://yi622.github.io/firdi-yy-/sensory.html)** (`sensory.html`)
    *   用於評估不同配方的感官指標（甜度、酸度、香氣、口感）。

## 數據文件

*   `0604.csv`: 0604 批次的感官評分數據。
*   `食研所.txt`: 留樣樣品清單。

## 使用說明

1.  在 GitHub 設定中開啟 Pages 功能並選擇 `main` 分支。
2.  點擊上方連結即可使用。
